# IS 1200 (Part IX):1973 — Method of Measurement: Roof Covering (Including Cladding)

Part of the [[IS 1200 - Method of Measurement Index|IS 1200]] series. General series rules in [[IS 1200 Part 1 - Earthwork]]. Source: `...\1200_9.pdf` (11 pages, incl. Amendment 1). Extracted text: `<local extracted text>\IS 1200\IS-1200-Part9-fulltext.txt`.

## General measurement rules for roofing (Cl 2)
- Work in snow measured separately (this Part's series-rule variation drops the water/mud/tide items from Part 1's list, keeping only snow).
- **Superficial area measured on the flat, m², no allowance for laps or corrugations.** Portions overlapped by ridge/hip are included in the roof measurement (unless stated otherwise).
- **Openings ≤0.4 m² not deducted** (cutting for them enumerated separately); **>0.4 m² deducted**, with the cutting measured in running metres.
- Cutting **across** corrugations is measured on the flat, not girthed (i.e. not measured along the wavy profile). No addition for laps cut through.
- Curved/bent-to-curvature sheeting measured separately.
- Woodwork and steelwork supporting the roof are measured separately under their own Parts (→ Part 8, Part 21).

## Metal sheet roofing (Cl 3)
Type+thickness described; side/end laps stated (and bolt/rivet spacing if bolted/riveted). **Nainital pattern sheet roofing** — fully described, separate, includes all rolls/clips, measured flat not girthed. **Ridges/hips/valleys** — running metres along the centre line, girth stated; flashings — m²; laps/passings/fixing method described but **not measured separately** (i.e. lap length along a ridge/hip/valley/flashing is deemed included, not billed as extra).

## Asbestos cement roofing (Cl 4)
Type+thickness described; laps stated, fixing method described (maker's-instructions fixing stated if applicable). Ridges/hips — running metres along centre line, laps stated (two-piece ridges measured as one length). Ridge finials, cowl-type ventilators, curved north-light barge boards, roof lights, ridge/north-light expansion joints — enumerated (two-piece interlocking finials count as one). Eaves fillers, aprons, barge boards, corner pieces, flashings, louvers, north-light/ventilator curves, sheet expansion joints and similar specials — running metres of finished work, laps+fixing stated. Dissimilar-material ventilator sheets — enumerated as extra-over ordinary sheeting. Eaves/valley gutters — running metres along centre line. Gutter accessories (drop ends, stop ends, nozzles, angles) — enumerated as extra-over gutters. Union clips (loose sockets) — **never measured separately**.

## Other roof sheeting, cladding, tiling (Cl 5–9)
- **Roof sheeting other than metal/AC** (plastic, fibreglass, etc.) — Cl 4's method applies directly.
- **Cladding** (plain/corrugated/semi-corrugated) — type+thickness described, laps stated, fixing (incl. bolt/rivet spacing) described.
- **Roof tiling:** kind/pattern/quality/size/gauge/laying-method described. Single vs double tiling measured separately. Ridges/hips/valleys — running metres (mortar bedding stated if used). Special ridge/hip tiles — described (kind/pattern/quality/size + bedding/pointing mortar, incl. colour-matched mortar). Hip hooks — enumerated, size + black-or-galvanized stated. Eaves tiles bedded in mortar on walls — running metres as extra for eaves, mortar+bedding-width described. Filling ends/spaces between tiles at eaves — running metres, depth stated. Single vs double filling measured separately. Screwing eaves tiles to battens — running metres, screw type/size/spacing/washers stated (drilling holes included). Half/1.5 tiles at verges not measured separately — the straight cutting/waste along the full verge length is what's billed instead, running metres. Tiles at verges bedded on walls — running metres as extra-over for verges. Country tiling — described, all cutting/waste included. Special ventilating/glass tiles — enumerated as extra-over ordinary tiling.
- **Roof shingles and roof slating** — both measured the same way as roof tiling (Cl 7).

## Terraced roofing (Cl 10)
Size/quality of burnt bricks, brick tiles, stone slabs etc. described, plus laying/jointing/pointing method, mortar mix+type, number of brick/tile layers.
- **Madras terrace roofing** — fully described, plaster finish top+underside included in the item.
- **Flat brick tile roofing** — thickness + number of layers stated.
- **Hollow roof** (brick-on-edge bridging courses between two tile layers) — fully described, measured separately.
- Flush pointing to tile top/underside — included in the roofing item (not separate).
- **Tiles in CHAJJAS and sun-shades — measured separately** from the main roof tiling.
- **Stone slab roofing** — stone type/quality/dressing described, slab thickness + batten/joist spacing stated; uniform slab size stated if required.
- **Jack arch roofing** (incl. centering provision) — measured flat overall, m²; clear span, rise, arch thickness, laying/jointing/pointing method described; top+underside finish stated and included.

## Roof treatment (Cl 11)
Lime concrete in terracing — m², consolidated average thickness stated. Mud terraced roof — described, average consolidated thickness stated. **Waterproofing treatment** — each type fully described (material type/quality/quantity, laps), measured in m²; all cutting, waste, opening formation, and edge wedging/pointing into masonry included. Turn-ups/turn-downs at eaves/verges/abutments measured along with the waterproofing item. Primer (where provided) measured separately. Waterproofing in flashings/aprons/gutters/hips/ridges/valleys — fully described, net, separately, m². Waterproofing between corrugated-sheet laps — fully described (incl. securing method), running metres, width stated.

## Thatching, matting, bamboo work (Cl 12)
Fibre/straw kind + finished thickness described; bamboo/wood securing fillers, tying string, eaves/verge trimming included. Thatched ridge/hip capping — running metres along centre line, girth stated. Matting — material/layers/laps/fixing described, all cutting/waste included. Cover strips/cross-bracings (split bamboo or wood laths) — m² as extra-over matting. One-way vs two-way JAFFRI bamboo work — each measured separately, m², bamboo size+spacing stated, framing included. Split-bamboo vs whole-bamboo work — measured separately. Whole bamboos as independent matting supports — running metres, mean girth stated, fixing method + preservative application described.

## Rainwater goods (Cl 13)
Gutters/pipes — running metres incl. all short lengths/cutting/waste; material, protective coating, pattern, jointing/fixing described; length along the centre line, fitting lengths (bends/junctions/angles) included. Gutter brackets — measured separately under the relevant steelwork/woodwork Part. Angles (internal/external), drop ends, stopped ends — enumerated as extra-over gutter length, incl. extra joints/cutting/waste. Pipe rails, distance pieces, holder bats — described, included with pipe fixing. Bends/elbows/offsets/shoes/branches/swan necks/heads — enumerated as extra-over pipe length, incl. extra joints/cutting/waste.
