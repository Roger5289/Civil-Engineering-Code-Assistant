# IS 1200 (Part IV):1976 — Method of Measurement: Stone Masonry

Part of the [[IS 1200 - Method of Measurement Index|IS 1200]] series. General series rules in [[IS 1200 Part 1 - Earthwork]]. Source: `...\1200_4.pdf` (13 pages). Extracted text: `<local extracted text>\IS 1200\IS-1200-Part4-fulltext.txt`. Structurally near-identical to [[IS 1200 Part 3 - Brickwork]] with stone-specific substitutions — read that note for the shared pattern; this one flags what differs.

## General walling (Cl 3)
Stone type, walling kind, mortar mix fully described.
- **Deemed included:** bond stones; raking joints for plaster/pointing or flush-finish; preparing existing wall tops for raising; rough cutting/waste (gables, arch cores, eaves splays, body cutting); pipe holes; building-in holdfasts/air bricks/fixing bricks; bedding wall plates/lintels/sills/tiles/sheets; building-in joist/beam/lintel ends + making good; forming openings/flues (no deduction, see below).
- **Random/uncoursed rubble brought up to courses:** measured separately, stating min/max course heights. **Coursed work:** course height stated (or, if regularly diminishing, max/min heights).
- **Circular walling:** mean radius ≤6 m — separate, cutting/waste/templates included. >6 m — measured net, included with general walling.
- **Included with general walling:** footings; battered masonry (net; battered surfaces separately as extra-over, m²); eaves/beam filling (no deduction); chimney breast/stack/flue walling; pilasters.

## Measurement (Cl 4)
- **Base unit: cubic metres**; **face work in m²**.
- **No deduction/addition for:** dissimilar-material ends ≤0.1 m² section; openings ≤0.1 m² (same lintel/reveal note as brickwork); wall/bed-plate and slab/CHAJJA bearings ≤10 cm thickness not spanning full wall thickness; holdfast/holding-down-bolt concrete blocks; iron fixtures (wall ties, pipes ≤300 mm dia, door/window holdfasts).
- **Fireplaces/flues** ≤0.20 m² sectional area — measured solid, no extra pargetting/coring measurement. >0.20 m² — deduct void, pargetting/coring in running metres stating size. Apertures not deducted, no extra jamb/throating labour.
- **Pillars/columns:** m³; rectangular/polygonal, curved-on-plan, or other. *Rectangular = breadth ≤3× thickness and thickness ≤60 cm* (note: brickwork's equivalent definition uses "3 brick lengths" — stone's is a flat 60 cm, a genuine difference between the two Parts, not an inconsistency to flag).

## Stone-specific categories (Cl 5–20)
- **Stone nogging** — m², thickness stated, both-face facework included, overall dimensions. Timber framing separate (→ Part XXI).
- **Arches/vaults** — separate; centering ≤2 m span included, >2 m separate (→ Part V). Facings to arches measured separately.
- **Underpinning** — separate; wedging on top with thin slabs/slates — m² (length × top-course width).
- **Levelling up** (uncoursed random walling for DPC/band courses) — separate, m², levelling material (concrete/mortar) described.
- **Facings:** same-stone-as-body facing → described as "extra-over" walling for the extra dressing labour. Bed/joint dressing stated if applicable. Different-stone facing → described as "stone and labour in facing," type + average bed + bonder count/m² stated; bonding to stone/brick walling measured separately. Circular facing ≤6 m radius — radius stated; >6 m — included with general facing.
- **Arches in facings:** dressing — m² (face + exposed soffit), rise/soffit-width stated, joints described. Random-rubble arches include skewback/over-arch/under-arch cutting; superior facework's arch-cutting is separate, running metres.
- **Angles in facings:** external angles — running metres (larger quoin-stone size stated if applicable; drafted margins described with width). Squints/birds-mouths/splayed-or-rounded angles — each separate, running metres, splay width or rounded girth stated. Same again for battered facings, noting horizontal joints on battered quoins if present.
- **Chases/rebates/throatings/grooves:** running metres, girth stated, classified ≤10 cm and 10–20 cm girth (throating always separate); >20 cm girth → m².
- **Cutting holes:** per cm depth, classified ≤400 cm² and 400 cm²–0.1 m².
- **Cutting openings** >0.1 m² — **m³** (unlike brickwork, stone doesn't split by wall-thickness band).
- **Toothing and bonding** — m² of contact surface, new work only; toothing spacing/size stated.
- **Dressed stonework** (sills, steps, string courses, cornices, columns, caps, copings, lintels) — m³ each; dressing type described + measured separately as extra-over, m². CHAJJAS/JALLIES/shelves in dressed stone — m² inclusive of bearing. **Each stone measured as the smallest rectangular block the finished dressed stone could be worked from** (a stone-specific billing convention with no brickwork equivalent — bills the raw block size, not the finished profile).
- **Additional dressing labour:** sunk work (arch faces/beds/joints, voussoirs, key blocks, splays, batters, weatherings) and moulded work (cornice girth) — m² if >10 cm girth/width, else running metres. Chamfers/arrises/splays ≤1.5 cm width vs 1.5–10 cm width — separate bands, running metres. Rounded bullnose/hollow angles, rebated/grooved facework or joint/tongue grooves, chisel-drafted margins — running metres if ≤10 cm. Drilled/cut holes — enumerated, diameter+depth stated. Rectangular/dovetail mortices — enumerated, size in cm³; running with cement/lead described.
- **Stops, mitres, returned ends** — described and enumerated.
- **Curved figures/letters** — described, enumerated, dimensions stated.
- **Boulder work** — m³, boulder size stated; classified: dry hand-packed filling; dry walling; walling in mortar (mix stated).
