# IS 1200 (Part 23):1988 — Method of Measurement: Piling

Part of the [[IS 1200 - Method of Measurement Index|IS 1200]] series. General series rules in [[IS 1200 Part 1 - Earthwork]]. Source: `...\1200_23.pdf` (7 pages). Extracted text: `<local extracted text>\IS 1200\IS-1200-Part23-fulltext.txt`. Fourth revision's main updates: RCC sheet piles, timber sheet piles, bored piles.

## General rules for this Part (Cl 2)
- Work-measured-separately: situations (in/under water, liquid mud, marshy land, tidal) stated as they occur; high/low tide levels stated.
- Site nature described generally; **available strata information stated, or bore records referenced.**
- If piles start from a level other than ground level, stated. Piling-frame raising/lowering described with exact height+working nature; **separate items for raker/grouped/isolated/lengthened/trial piles.**
- Items include any extra excavation/filling/ramming needed to move the piling frame during piling.
- **Bringing plant to site + erecting, and dismantling + removing** — measured separately as **lump-sum items**. (Shifting plant *within* the site is included in the pile item itself, not separate.)
- **Load testing**, if required — specified and measured separately.

## Precast reinforced concrete piles (Cl 3)
Described by concrete grade, section, length; extra head-strength stated. Requisite mould, strapping, bolts, lifting holes included in the description.
- **Concrete: m³ = cross-sectional area × cast length (pile head to shoe tip).** No deduction for chamfers, tapered points, reinforcement volume, or lifting holes.
- Formwork, links, sleeves — included in the description. **Reinforcement measured separately** (→ [[IS 1200 Part 8 - Steelwork and Ironwork]]).
- **Shoes** — enumerated separately per size, approximate weight stated.
- **Driving** (to a given level, incl. redriving lengthened piles) — running metres, **separate bands for ≤5 m length, then every 1 m range beyond that.** Measured from the shoe tip to the drawing level. Raker piles measured along the pile axis.
- Handling/transportation/pitching — enumerated per occasion.
- **Stripping pile heads:** length stated, measured per linear metre. Stripping for bond length — enumerated.
- **Lengthening piles in position** (after lowering) — the added concrete is a **separate item**, including the extra labour to strip the exposed end for the new-to-old connection, plus any required excavation.

## Timber piles (Cl 4)
Described + measured in running metres, species stated (per IS 2911 Part 2), size stated. **Length beyond 5.0 m measured in 1 m stages.**
- **Diameter = girth measured 2 m below the pile's large end.** Cross-section tolerance stated where permitted.
- Shaping + shoeing — enumerated, approximate shoe weight + pile size stated.
- Handling/transport/pitching — enumerated per occasion.
- **Driving** — same method as Cl 3.7 (concrete piles), tip-of-shoe to drawing/site ground level. Item also includes top-cutting + dressing for the mild-steel anti-split ring.
- Iron-ring supply+fixing before driving, and cutting off any ringed/damaged portion — included in the item.
- Joints in piles — described, enumerated.

## Steel sheet piles, permanent (Cl 5)
Supply-only — **by weight** (→ Part 8), incl. cross-sectional shape, manufacturer nomenclature, material spec, fabrication details (lengthening by welding/riveting/drilling/burning holes, joining rolled sections), handling/transport. **Piles >12 m length described separately, further staged in 3 m increments.**
- Struts, anchor bolts, anchor plates, turnbuckles, walling — measured separately (→ Part 8).
- Pre-driving painting — m², = length × fabricated-pile perimeter along the profile; surface prep, coat count, painting mode described.
- **Lifting/handling/pitching/engaging through interlocks or clutches + driving** — measured separately per type, **m² = embedded-portion length × half the perimeter** (per IS 2314-1986). Embedded length = ground level (where the tip first touches before driving) to the final tip level after driving.
- Piles driven under/in water needing special hammers/loader frames — described+measured separately.
- Corner/junction pile driving — running metres, representing embedment length.
- Cutting/burning through steel piles — running metres, extra-over the pile; cut-length disposal described.
- **Extraction** (other than corner/junction piles) — m², = embedded length × nominal pile width from the clutch centre; lifting/handling/site removal described+included.

## Cast-in-situ driven concrete piles (Cl 6)
Described by nominal diameter, concrete grade, aggregate size, reinforcing bars, cage length, pile length.
- **Forming pile shafts (incl. concrete + driving casings to a given level) — one item, running metres.**
- Reinforcement (incl. pile-cap embedment bars) — measured separately (→ Part 8).
- **Cast-in-situ pile length: toe to cut-off level.** Description states casing diameter+type, concrete grade, core reinforcement details.
- Pile shoe provision — included in the item.
- **Empty boring** — measured separately, running metres, working-ground-level to cut-off level; filling type stated.

## Cast-in-situ bored reinforced concrete piles (Cl 7)
Empty boring — separate, running metres, working level to cut-off level, filling type stated. **Boring through boulders/rock strata — extra-over.** Reinforcement (incl. cap-embedment bars) — measured separately. Description states nominal diameter, concrete grade, aggregate size, reinforcing bars, cage length, liner provision.
- **Permanent mild steel liners** — measured separately, by weight (→ Part 8), working level to foundation level.
- **Under-reamed/bulb-based piles:** bulbs measured+enumerated, bulb diameter stated.

## Reinforced cement concrete sheet piles (Cl 8)
- **Concrete: m³ = cross-sectional area × cast length** (head to shoe tip) — same formula as Cl 3.2.
- Description: cross-sectional shape, concrete grade, aggregate size, extra head strength; mould/strapping/bolts/lifting holes included.
- **Lifting/handling/pitching/engaging through adjacent piles + driving** — measured separately per type, **m² = embedded length × half the section's perimeter** (same embedment-measurement convention as Cl 5.4).
- Underwater/special-hammer driving — described+measured separately. Corner/junction driving — measured separately. Cutting — running metres, extra-over, disposal described. Extraction (non-defective-driving cases) — m², per Cl 8.3's method.

## Timber sheet piles (Cl 9)
Described+measured running metres, species+cross-section stated. Handling/transport/pitching — enumerated per occasion. **Driving — m² = embedded length × half the perimeter.** Underwater/special-hammer driving — separate. Corner/junction piles — separate. Cutting — running metres extra-over, disposal described. Extraction (non-defective cases) — as Cl 9.3's method.

## Bored precast concrete piles (Cl 10)
Described (concrete grade, aggregate size, section, length, extra head strength; mould/strapping/bolts/lifting holes included). **Concrete: m³ = cross-sectional area × cast length**, no chamfer/taper/reinforcement/lifting-hole deduction. Formwork/links/sleeves included. Reinforcement measured separately. **Placing pile shaft — running metres, founding level to working level.** Empty boring — separate, running metres, working ground level to cut-off level; **boring through boulders/rock (except isolated boulders ≤ the pile-shaft diameter) — extra-over.** Handling/transport/pitching — enumerated per occasion. Stripping pile heads — length stated, running metres. Stripping for bond length — enumerated. **Grouting — m³, method fully described.**
