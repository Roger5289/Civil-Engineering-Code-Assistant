# IS 1200 (Part VII):1972 — Method of Measurement: Hardware

Part of the [[IS 1200 - Method of Measurement Index|IS 1200]] series. General series rules in [[IS 1200 Part 1 - Earthwork]]. Source: `...\1200_7.pdf` (8 pages, incl. Amendments 1 & 2). Extracted text: `<local extracted text>\IS 1200\IS-1200-Part7-fulltext.txt`. Builders' ironmongery — bolts, hinges, locks, latches, fasteners, closers.

## General rules (Cl 2)
- Description deemed to include: conveyance/delivery/handling/unloading/storing, all fitting/fixing labour, cutting/waste, pack return.
- Dimensions measured net, nearest 0.01 m (this Part omits the series' separate area/volume precision clauses — hardware items are inherently linear/enumerated).
- **Mode of measurement:** each kind of hardware described and measured separately by material, finish, size, pattern, and fixing method.
- **Default unit: enumerated**, for essentially everything **except** these four, which are **running metres**: curtain rods/poles (stating outer diameter); curtain rails (runners/brackets/stops described and included in the item, stating number per metre of rail); sliding-sash rails (size stated); sash lines (girth/diameter stated).
- Fixing is deemed to include all cutting/sinking/boring/morticing plus matching screws (or bolts/nuts/washers for bolt-fixed hardware).
- Hardware fixed to wood vs metal — measured **separately**. Flush-fixed hardware — stated as such.

## Table 1 — how each article's size is measured (Cl 3.1)
The standard's core content is a lookup table defining *what dimension counts as "the size"* for ~33 hardware types — not something with a formula or numeric grid, so it's captured here as a reference list rather than reproduced table-for-table. Selected examples to illustrate the pattern (source p.5–7 has the full 33-row list):
- **Bolts:** flush bolts — face-plate length; other bolts — shoot (bolt) length.
- **Hinges:** butt hinges — joint/knuckle length; parliament hinges — width between flanges + height; tee/strap hinges — leaf length (joint to point); spring butt hinges — spring-cylinder length; back-flap hinges — joint length.
- **Latches (Suffolk/Norfolk):** plate dimensions (with bow handle) + size number.
- **Locks (rim, mortice, cabinet/cupboard, drawer, furniture):** each has its own stated measurement convention — see source table.
- **Door closer (hydraulic):** weight + door width it's designed for.
- **Casement fasteners/stays:** extreme length including back-plate thickness (fasteners); shortest straight end-to-end length (quadrant stays).
- **Door handles:** grip length. **Finger plates:** length × width × thickness.
- **Sliding door bolt (aldrop):** bolt length. **Floor door stopper with plate:** plate length. **Hooks and eyes:** hook length, out-to-out.

**Practical note:** because this table defines measurement convention rather than giving numeric values, it doesn't carry the multi-column-scrambling risk this vault has flagged elsewhere (IS 875, SP 16/34) — it read clean on a single linear extraction pass, consistent with being a definitions list, not a data grid.
