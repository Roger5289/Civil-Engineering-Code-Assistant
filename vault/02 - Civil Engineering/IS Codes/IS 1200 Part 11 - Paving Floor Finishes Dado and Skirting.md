# IS 1200 (Part XI):1977 — Method of Measurement: Paving, Floor Finishes, Dado and Skirting

Part of the [[IS 1200 - Method of Measurement Index|IS 1200]] series. General series rules in [[IS 1200 Part 1 - Earthwork]]. Source: `...\1200_11.pdf` (11 pages, incl. Amendment 1). Extracted text: `<local extracted text>\IS 1200\IS-1200-Part11-fulltext.txt`. Airfield pavement measurement is covered by Part XVII, not here.

## General rules for this Part (Cl 2)
- **Length/breadth measured before laying skirting, dado or wall plaster** — a specific sequencing rule this Part adds.
- **Base unit: m²** unless stated otherwise. **No deduction for ends of dissimilar materials/embedded articles ≤0.1 m².**
- **Isolated width not matching the general finish:** ≤30 cm width → running metres (incl. edge cutting); >30 cm → m².
- Expansion/dummy joints — running metres, separately, depth+width stated; filler material described within the item.
- Repair work — described as such, old-surface prep included.
- Isolated areas ≤1 m² each — described, stating the nature.
- Patterned or multi-colour work — described, stating the nature.
- Curved/conical/spherical work — described separately, radius stated; its extra labour measured separately too.

## In-situ finishes (Cl 3) — granolithic, terrazzo, mosaic, etc.
Classified by material, each measured separately, stating: composition/mix; thickness (excl. keys/grooves/open joints); number of coats; surface treatment (steel-trowelled, wood-floated, polished, carborundum-sprinkled, etc.); base nature + special treatment; location (flooring vs dado/skirting).
- Imitation stone-slab/block work — described, average slab/block size + finish stated.
- Floors laid in bays, or in panels between dividing strips — size of bay/panel stated; dividing strips measured separately (Cl 3.13).
- Floors laid in one operation with the base concrete — stated as such.
- **No deduction for voids ≤0.2 m².**
- Treads/risers/landing edges — m² (landings included in the main item). Wall strings/open strings — m² (ends/angles/ramps/wreathed corners included). Moulded nosings — running metres (returned ends/angles included).
- **Dados** (incl. raking) — m². **Skirting** (incl. raking) — running metres, height stated. Mitres/stops/returned ends included with the item.
- Kerbs — running metres, face girth stated; raking vs vertical kerbs described separately; arrises/rounded edges/coves included; angles/intersections enumerated separately.
- Channels — running metres as extra-over the surrounding finish, face girth stated, arrises included; ends/angles/intersections/outlets each enumerated separately. Channel lining — same, separately.
- Dividing strips — described (size+thickness), running metres, separately; ends/angles/intersections/fixing method included.

## Tile, slab or block finishes (Cl 4)
Particulars required: unit kind (precast concrete [mix stated]/terrazzo/brick/natural stone/cast stone/slate/marble/woodblock/cork/rubber); thickness+size; shape (if non-rectangular); surface finish; bedding/fixing method; joint grouting/pointing/finish; base nature; location; joint layout.
- Temporary moulds for precast units — deemed included.
- **No deduction for voids ≤0.2 m².**
- Square cutting at joints/boundaries — deemed included (except Cl 4.5 below). Raking/curved cutting — running metres, separate, except within a pattern. Diagonal-pattern boundary straight-cutting (around each area's perimeter) — running metres.
- **Fair/rebated/rounded/chamfered/splayed/bevelled edges** — running metres, separate, incl. ends/angles/mitres/intersections.
- Moulded edges/grooves/flutes — running metres, separate; ends/angles/intersections enumerated separately.
- Cutting/fitting around grouped steel stanchions — described, enumerated. Around pipes/tubes/bars/cables/conduits — described, enumerated. Around step profiles — enumerated. Around grouped ducting brackets/newels/WC pedestals/vents/soot-doors — enumerated, size stated **in 25 cm girth stages**.
- Dividing strips, dados, skirting — same as Cl 3 above.
- Channels + channel lining — each running metres, section+average depth described; falls-channels stated; rounded edges included; ends/angles/intersections/outlets enumerated separately. Kerbs — running metres, section described, rounded edges/coves included.
- Special tiles/slabs (coved internal angles any radius, rounded external angles, architraves, mouldings, ceiling ribs, cornices) — each running metres, by size+shape.
- Treads/risers/landing edges — m², separate (landings in the main item).

## Sheet finishes (Cl 5) — linoleum, cork, rubber, etc.
Particulars: sheeting kind; thickness+quality; fixing/joining method; base nature.
- Laps/seams — described (lap + seam type), **not measured separately**.
- Vertical/inclined/horizontal surfaces — measured separately.
- **No deduction for voids ≤0.2 m².**
- Raking/curved cutting — running metres, separate, except within a pattern. Rounded external angles / coved internal angles — running metres, separate, girth stated.
- Cover strips over joints — described (size), running metres, ends/angles/intersections included.
- Cutting/fitting around stanchions, pipes/cables, step profiles, grouped fixtures — same rules as Cl 4 (enumerated, 25 cm girth stages for the grouped-fixture category).

## Bedding and backings (Cl 6)
Particulars: composition/mix; thickness (excl. keys/grooves/joints); base nature+treatment.
Screeded beds for all floor finishes — described, measured. **No deduction for voids ≤0.2 m².** Bays/panels between dividing strips — size stated. Treads/risers/landing edges — m², separate (landings in main item). Skirting/dado bedding+backing — measured separately. Channels in beds — running metres as extra-over the bed, face girth stated; arrises/rounded edges/coves/ends/angles/intersections/outlets included.
