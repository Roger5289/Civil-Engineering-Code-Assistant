# IS 1200 (Part 15):1987 — Method of Measurement: Painting, Polishing, Varnishing, etc

Part of the [[IS 1200 - Method of Measurement Index|IS 1200]] series. General series rules in [[IS 1200 Part 1 - Earthwork]]. Source: `...\1200_15.pdf` (12 pages, incl. Amendment 1 — May 2002, reflected below). Extracted text: `<local extracted text>\IS 1200\IS-1200-Part15-fulltext.txt`. **Distinct from [[IS 1200 Part 13 - Whitewashing Colour Washing Distempering and Painting]]**, which covers only whitewash/distemper/waterproof paint on building surfaces — this Part covers general paint/polish/varnish across all surface types (steel, joinery, doors, gates, structural work).

## General rules (Cl 2)
Preparatory work (knotting, priming, stopping, rubbing down, burning off/stripping) — described, coat count stated; work on previously-painted surfaces measured separately; special colours/finishes stated if required.
- **Surfaces measured separately, classified:** non-absorbent (steel, metals) vs semi-absorbent (wood, fibre-board) — preparatory work described and included in each item.

## Measurement (Cl 3)
- **Base unit: m²** unless stated. **No deduction for openings ≤0.5 m² each**, and no addition for beading/moulding/edges/jambs/soffits/sills of such openings.
- **Fabricated structural steel/iron:** priming coat included with fabrication; **subsequent coats measured separately, by weight of the steelwork or in m²** (weight/area taken from relevant IS standards, per [[IS 1200 Part 8 - Steelwork and Ironwork]]'s conventions). Rivet/bolt/nut heads picked out in a different tint — enumerated as extra-over. **No addition to steelwork's calculated weight for the paint itself** (shop or site-applied).
- **Narrow-width work** ≤10 cm width/girth, not in conjunction with similar painted work — running metres, incl. cutting to line. Cutting to line, where not included — separate, running metres.
- **Small articles** ≤0.1 m² painted surface, not in conjunction with similar work — enumerated.
- Different work types kept separate, surfaces described, flat-or-girthed stated. **Alternatively, group into one general item using Table 1's equivalent-plain-area multipliers** (below).
- **Corrugated/Nainital-pattern surfaces folded into plain-surface area** with the amended (2002) multipliers: **M.S. & G.I. corrugated sheets +14%**; Nainital plain-with-rolls +10%; Nainital with corrugated sheets +25%; AC corrugated +20%; AC semi-corrugated +10%; **aluminium corrugated sheet +12% (added by the 2002 amendment)**.
- Eaves-gutters, rainwater/soil/vent pipes, steel poles — running metres, size/girth stated, fittings (bends/shoes/branches/heads) included in the length.
- Small articles picked out differently or standalone (gate/turn straps, ceiling roses, switch-blocks, nuts/bolts, hardware) — enumerated.
- Special-scaffolding items (flag staffs, chimneys, unlatticed aerial masts, water tanks, floodlight towers, overhead electric masts, spires) — measured separately, size/height/average girth stated.
- **Repair-work painting ≤1 m²** — enumerated in bands: ≤0.1 m²; 0.1–0.5 m²; 0.5–1 m². (>1 m² follows the normal Cl 2.6/general rule.)

## Table 1 — equivalent plain areas of uneven surfaces (the core reference table)
All measured **flat, not girthed**, unless noted; multiplying factor applied to the flat/opening area to get the billable equivalent:

| Work | Multiplier |
|---|---|
| Panelled/framed/braced/ledged/battened joinery (incl. CHOWKAT/frame; edges/chocks/cleats included) | **1.30** each side |
| Flush joinery | **1.20** each side |
| Flush shutter | **1.20** each side |
| Fully glazed/gauzed joinery | **0.80** each side |
| Partly panelled + partly glazed/gauzed joinery | **1** each side |
| Fully venetianed/louvred joinery | **1.80** each side |
| Weather boarding | **1.20** each side |
| Wood shingle roofing | **1.10** each side |
| Boarding with cover fillets/match boarding | **1.05** each side |
| Tile and slate battening | **0.80** all over |
| Trellis (JAFFRI) work, one/two-way (no deduction for open spaces) | **2** all over |
| Guard bars, balustrades, gates, gratings, grills, expanded metal, railings | **1** all over |
| Gates and open palisade fencing (incl. standards/braces/rails/stays) | **1** all over |
| Carved or enriched work | **2** each side |
| Steel roller shutters (opening size; jamb guides/bottom rails/locking incl.; top cover separate) | **1.10** each side |
| Plain sheet steel doors/windows (incl. frame/edges) | **1.10** each side |
| Fully glazed/gauzed steel doors/windows (incl. frame/edges) | **0.50** each side |
| Partly panelled + partly glazed/gauzed steel doors | **0.80** each side |
| Collapsible gate (opening size) | **1.50** all over |

**Notes to Table 1:** (1) Palisade-fencing height is measured from the lowest rail's bottom (or palisade bottom if it projects below the rail) up to the palisade top — never up to the standards' top if they're higher. (2) Composite door/window types not in the table are split at the common rail's centreline, each portion measured with its own coefficient. (3) Table-measured painting of doors/windows/gates/shutters deems iron-fitting painting (same shade) included. (4) Two faces with different specified finishes: frame/shutter edges follow whichever finish they're treated with, and that measurement counts toward that finish's item. (5) Shutters on both faces of one frame: one face's measurement includes the frame per the normal method; the additional far-face shutter is measured exclusive of the frame. (6) Shutter clearance >15 cm top/bottom: deduct that opening from the overall measurement and apply the relevant coefficient. **(7) Added by the 2002 amendment: multipliers for any other intermediate case not covered above should be derived in line with the factors already given in the table** — i.e. interpolate/extrapolate by analogy rather than treat the table as exhaustive.

## Varnishing, polishing, preservative, tarring, lettering (Cl 4–8)
- **Varnishing:** sizing/staining/varnishing on woodwork follows Cl 3's provisions directly.
- **Polishing:** woodwork polishing (incl. preparatory work + bodying-in) — m², per Cl 3; alternatively, described + enumerated as articles.
- **Preservative treatment:** surface-applied wood preservative — m², irrespective of girth/size, per Cl 3.
- **Tarring:** measured as painting, per Cl 3.
- **Writing letters/figures:** enumerated, height + style (block/italic etc.) stated; stops/commas/hyphens deemed included.
