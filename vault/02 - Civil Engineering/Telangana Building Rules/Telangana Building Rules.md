# Telangana Building Rules

Folder index for Telangana-specific building/development orders, as distinct from national ([[NBC 2026]]) and Bureau of Indian Standards ([[IS Codes]]) material. Part of the Code Design Assistant.

- [[GO 168 - Telangana Building Rules 2012]] — the base building bye-law order (G.O.Ms.No.168, dt.07.04.2012). Complete: Main Rules 1–29 plus all Annexures III–XII (Multiplex Complex Rules, High-Rise Hospital Fire Rules, NBC accessibility, rainwater harvesting, protected-temple list, TDR register/agreement templates, builder/technical-personnel licensing, permit application form), all converted to structured/checkable form and audited (every numeric threshold in Annexures III/IV/V/VI/IX/X re-checked against source text — zero errors found). **5 of 6 known amendment G.O.s downloaded and incorporated inline** (342/2013, 7/2016, 62/2020, 103/2021, 52/2022) — every changed rule is marked `[AMENDED BY G.O.___]` in place, including a case where a later G.O. (62/2020) reverses an earlier one (7/2016) on permit validity. Only G.O.95/2026 remains ungettable — see the note's top section.
- [[GO 168 Annexure I-II - Locality Schedule]] — the per-town (141 ULBs, undivided AP) Old/Congested-Area and High-Rise-Prohibited-Zone lists, captured in full.
