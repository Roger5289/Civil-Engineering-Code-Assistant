# NBC 2026 (National Building Construction Standards 2026 / SP 7:2026)

Structured, page-anchored reference for the National Building Construction Standards 2026 (Bureau of Indian Standards, SP 7:2026, fourth revision — supersedes NBC 2016). ## Coverage status

**All 21 sections + the Topic Index are VERIFIED against the source PDF (2026-09-05).** Every "verified" row below names what was checked and what (if anything) was fixed.

Status key: **verified** = audited against the PDF, numbers/anchors/tables checked · **partial** / **pending** — no longer used, kept for history.

**The deep audit (2026-09-05)** checked ~700 values across all 21 sections. **3 real errors found and fixed:**
1. Part C Sec 1 — vehicle-barrier force formula (was `mv²/(250(b+c))`, gives ~1 kN; corrected to `0.5·m·v²/(δc+δb)`, δ in mm, gives the code's stated 150 kN).
2. Part C Sec 5 — Table 8 max-height column mislabel (Zone V 180 m is wall+framed-tube, not wall+perimeter-frame which is 150 m).
3. Part D Sec 6 — the TBB conductor-sizing table's non-monotonic step (46–53 m → 185 mm², then 53–76 m → 150 mm²) is a **typo in the NBC 2026 source itself**, not a note error.

Improvements along the way: recovered a lost formula in C Sec 2 (Vesic k), confirmed + expanded C Sec 4 Table 12 (units are N/m², not the printed N/mm²), added the corrupted/missed Tables 7/11/12 to D Sec 1, wrote D Sec 5A, built the Topic Index, cleared ~10 over-cautious "verify against PDF" flags.

**Source-text corruption** in `NBC-2026-fulltext.txt` (broken subset font) was confined to exactly 3 spots, all handled: Part D Sec 5A (rewritten from clean extract), Part D Sec 1 Table 7 (recovered from PDF), Part E Sec 2 p.2583 glossary (flagged, prose only). **The main PDF** (`<your codes folder>\NBC 2026- Vol-1 & 2.pdf`) opens fine in **pymupdf** — use `d[N-1].get_text()` to pull any page clean; no re-exports needed.

Large numeric lookup tables that remain "read straight from the PDF" (too dense / column-order risk to transcribe): steel buckling curves (C6A Tables 8/9), glass wind-load charts (C8 Tables 17–26), lift dimension tables (5A Tables 14–32), pipe-sizing tables (E2 Tables 18–24), LPG safety distances (E4 Table 1), Annex construction-assembly tables (C4 E/F, D4 H). These are flagged in each note.

## Notes on fidelity

- Clause text and figure/table **captions** are transcribed from the actual extracted text.
- Numeric tables (load values, dimensional limits, fire ratings, etc.) are cross-checked against the PDF where extraction risked jumbling columns. Any value flagged "verify p.NNN" in a section note means the auto-extraction wasn't fully trustworthy for that table — open that PDF page before using the number for real design work.
- Drawings/figures are referenced by caption + page number, not visually transcribed (there are hundreds of embedded images; describing all of them wasn't a good use of budget). Ask for a specific figure by page number any time and it can be pulled and read directly.
